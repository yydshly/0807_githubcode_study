01 / WHO DOES WHAT

四层协作，Agents 位于中间

它不提供新的“大脑”，也不替代媒体服务器或业务控制面；它在中心连接房间，并分别编排模型和业务工具。

01实时媒体层

LiveKit

房间、参与者、音视频轨道、WebRTC、弱网传输和 SIP 电话。

02会话编排层

Agents

轮次、打断、管线、工具循环、Agent 交接、事件和任务调度。

03模型能力层

STT · LLM · TTS

把声音变成文字、理解与决策，再把回答变回声音。

04业务执行层

Tools · API

查询订单、日历、数据库或设备，并把确定性结果返回给模型。

一句话： LiveKit 是会议室和线路；Agents 是 AI 在其中运行、协作和执行任务的编排核心。

04 / RUN IT

三步进入真实本地房间

LiveKit、令牌服务和无 Key 文字 Agent 由一个脚本统一启动。

  1. 01
    进入子项目cd livekit-agents-study
  2. 02
    启动本地完整栈.\start-local.cmd
  3. 03
    打开真实房间控制台http://127.0.0.1:17828/
NEXT REAL STEP

已有 MiniMax 套餐，优先复用它

运行 .\start-minimax-local.cmd 即可使用已经实测的 MiniMax M3 与 Speech 2.8；再配置独立的 MIMO_API_KEY，页面会自动启用小米 ASR 麦克风输入。
