X / TwitterGrok → FxTwitter
搜索
Grok原生XSearch；仅明确额度耗尽后匿名回退
读取
FxTwitter读取Post、Quote、Article，Jina补正文
媒体
通用归档不下载；X Slicer为切片处理公开媒体

难点：搜索与已知对象解析分离，Article需定位父Status；非官方链路可能变化。

小红书INITIAL_STATE
搜索
OpenCLI站内搜索，需要当前任务Chrome授权
读取
匿名页面优先，解析window.__INITIAL_STATE__，meta回退
媒体
图片、视频、字幕和口播文本；Cookie仅授权后重试

难点：搜索依赖登录态，已知链接却优先匿名；页面结构和xsec参数易变。

抖音NETWORK INTERCEPT
搜索
OpenCLI站内搜索，需要Chrome授权，低频串行
读取
Playwright打开详情页，监听aweme/detail响应
媒体
选择play_addr/download_addr后流式下载视频

难点：依赖真实页面网络行为；不应在搜索阶段展开评论或自动下载。

微信公众号PUBLIC INDEX / EXPORTER
搜索
跨号关键词走公开搜狗微信索引
读取
已知文章通过本地exporter输出多种正文格式
容器
指定公众号历史需本地会话与用户自行扫码

难点：公共发现、单篇下载和账号历史是三条路线；绝不操作微信UI。

小宇宙SITE INDEX / AUDIO CDN
搜索
公共搜索引擎site:xiaoyuzhoufm.com
读取
解析已知episode页面和音频元数据
媒体
仅接受xyzcdn.net音频；可选StepFun转写

难点：没有稳定全站关键词接口；播客列表、音频下载和付费ASR分别授权。

B站BILI CLI / YT-DLP
搜索
bili search匿名获取视频候选
读取
BV、AV或完整URL规范化后读取结构数据
媒体
yt-dlp续传、防覆盖；播放列表先平铺

难点：高画质、会员、地区和年龄限制目标才单独申请Cookie授权。

YouTubeFLAT SEARCH / YT-DLP
搜索
flat ytsearch只返回元数据和URL
读取
已知URL使用dump-json或字幕路径
媒体
下载音视频、字幕；播放列表先固定清单

难点：发现、枚举和下载严格分层，不从条目扩展频道与相关推荐。

今日头条ANONYMOUS PROFILE
搜索
独立匿名环境，单关键词、低频、不自动重试
读取
公开文章可尝试普通网页路线
媒体
上游没有专用视频下载器

难点：当前路线只保留文章和非视频图文，完整内容支持明显弱于其他平台。

GitHubGH SEARCH
搜索
按仓库、代码、Issue和PR选择结构化接口
读取
搜索结果或网页内容
媒体
没有专用仓库归档和源码分析流水线

难点：搜索结构化程度高，但该仓库没有继续覆盖clone、依赖审计和运行验证。

公共网页ANYSEARCH / JINA
搜索
普通、批量、垂直领域和site限定
读取

媒体

难点：公开索引不等于全量；摘要只能用于发现，不能冒充原文证据。
