# ShadowBroker 覆盖面归档

> 归档日期：2026-08-07  
> 上游版本：v0.9.84  
> 提交：`8676a98945a31503180bc84f7c9dd092a3cc743d`

## 1. 覆盖面总览

ShadowBroker 横向覆盖范围很广，能够把多个领域的公开数据放到同一张地图和时间线上。但“包含一个领域”只代表存在一个或多个入口，不代表该领域的数据已经完整、权威或持续实时。

| 领域 | 已接入的主要信息 | 覆盖性质 | 时效判断 | 完整度判断 |
|---|---|---|---|---|
| 飞机/航空 | ADS-B 飞机位置、军机标签、机场、航线、飞机元数据、GPS 干扰推断 | 全球聚合网络 + 静态补充 | 部分位置秒到分钟级 | 中等；受广播、接收站和平台过滤限制 |
| 船舶/海洋 | AIS 船位、捕鱼事件、本地 AIS、舰队新闻线索 | 全球 AIS 聚合 + 事件推断 | AIS 可接近实时，新闻明显延迟 | 中等偏低；暗船、欺骗、远洋覆盖存在缺口 |
| 卫星/空间 | TLE/OMM 轨道、轨道推算、SatNOGS/TinyGS 地面站 | 公开轨道目录 + 本地计算 | 地图可连续更新，但不是实时遥测 | 中等；只能覆盖已编目且已发布轨道参数的目标 |
| 遥感 | Sentinel、SAR、夜光、NASA GIBS 等产品 | 产品目录、瓦片和资产文件 | 小时到日级，通常不是实时 | 中等；受过境、云、处理和发布周期限制 |
| 灾害 | 地震、火点、天气警报、火山、空气质量、太空天气 | 官方 Feed/API 为主 | 分钟到日级，因灾种不同 | 中等；缺少统一的全球地方应急覆盖 |
| 冲突/新闻 | GDELT、RSS、Telegram、前线图、空袭警报 | 新闻聚合、网页和事件解析 | 分钟到小时级 | 广但置信度不一；需要回到原始报道核验 |
| 网络/基础设施 | RIPE Atlas、IODA、电厂、数据中心、海缆、基地 | 网络观测 + 静态设施 | 网络指标分钟级，设施多为低频 | 静态布局较好，实时运行状态有限 |
| 交通/摄像头 | 列车位置、21 类道路摄像头目录 | 政府 API、KML、ArcGIS、媒体链接 | 目录约 10 分钟，媒体取决于上游 | 地域不均，入口容易变化 |
| 无线电 | APRS、Meshtastic、PSKReporter、KiwiSDR、JS8Call | 公共聚合、长连接、本地软件桥 | 部分接近实时 | 只覆盖参与网络或已有接收站的信号 |
| 网络安全 | 漏洞、恶意 URL/C2、证书、BGP、设备搜索 | Feed/API/按需查询 | 分钟到日级 | 线索丰富但存在误报、额度和授权边界 |
| 金融/预测市场 | Finnhub、Yahoo Finance、Polymarket、Kalshi | 公共或免费层 REST | 分钟级轮询 | 适合观察，不是交易级行情系统 |
| 地理背景 | OSM、Photon、Nominatim、Wikidata、Wikipedia、底图 | 地理编码、实体背景和瓦片 | 按需/缓存 | 用于解释和展示，不是实时观测 |

## 2. 三种“看到”必须分开

### 直接观测

目标或传感器产生信号，接收网络将其送入平台。例如 ADS-B、AIS、APRS、气象站和地震仪。即便属于直接观测，也会受到设备覆盖、断线、屏蔽、错误广播和平台过滤影响。

### 目录推算

平台提供一个较早时刻的参数，本地程序据此计算当前大概位置。卫星 TLE/OMM → SGP4 轨道推算是典型例子。地图上的点在移动，不代表正在接收卫星实时遥测。

### 新闻或规则推断

从新闻、名单、事件和其他观测中估算位置或风险。例如航母线索、GPS 干扰区和冲突事件。这类结果必须显示来源、时间和置信度，不能与直接传感器观测使用同一种视觉含义。

## 3. 各核心领域能回答什么

| 领域 | 可以大致回答 | 不能可靠回答 |
|---|---|---|
| 飞机 | 公开接收网络当前看到了哪些广播飞机、它们大概在哪里 | 全球所有飞机、所有军机、所有低空目标是否都存在 |
| 船舶 | 公共 AIS 当前收到哪些船位、部分捕鱼和靠港事件 | 关闭 AIS 的船、伪造位置的船、完整货运与任务信息 |
| 卫星 | 公开目录中有哪些已知目标、按轨道参数推算现在大概在哪 | 每颗卫星真实实时位置、遥测状态、任务和实时载荷内容 |
| 灾害 | 官方/社区 Feed 已发布了哪些事件 | 尚未被传感器确认或地方机构尚未发布的全部灾情 |
| 冲突 | 多个公开渠道正在报告哪些事情 | 报道是否已经独立证实、现场全貌和隐藏行动 |

## 4. 统计卫星时的口径

不能把地图点数直接叫“当前工作的卫星数量”。至少应按 NORAD Catalog ID 去重，并分为：

```text
全部编目空间物体
├── 活跃载荷
├── 失效卫星
├── 火箭级
├── 空间碎片
└── 状态不明物体
```

ShadowBroker 更适合展示选定 CelesTrak 分组中的已编目目标及其估算轨迹。它不是独立的空间监视雷达，也不能发现所有未知、敏感或刚发生机动的目标。

## 5. 当前来源规模

- 主来源及来源家族台账：83 条。
- 默认 RSS/Atom：22 条。
- 摄像头目录适配器：21 条。
- 接入方式：REST、OAuth2、WebSocket、TCP、MQTT、RSS、CSV/KML/ZIP、STAC/WMTS、网页解析、本地 HTTP 推送和媒体流等。

详细机器入口见 `source-entry-guide.md`；机器清单见 `../data/`。

## 6. 归档结论

ShadowBroker 的优势是横向覆盖和协议样本，不是任何一个领域的绝对完整度。它能给出公开信息下的“大概全球布局”和“正在被部分来源观察到的变化”，但不应被描述为全面、权威、无遗漏的实时监控系统。
